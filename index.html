测试版不连接云同步
· 为避免测试数据污染你的正式云库，测试版禁止开启云同步、也不读取你的云端数据。

隐私保障
· 数据经 AES-GCM 端到端加密后存于 GitHub Gist（私有），仅持有 Passcode 的你能解密
· 传输全程 HTTPS；GitHub 只看到密文
· Token 是访问凭证，Passcode 是加密钥匙——分开存放更安全
· 丢失 Passcode 无法恢复，请牢记；本地 localStorage 始终是你的离线兜底
添加到手机主屏幕

  1. 用手机浏览器（Safari / Chrome）打开本页面链接
  2. 点底部分享（iOS）或右上菜单（安卓）
  3. 选「添加到主屏幕」，桌面即出现图标
